# AGENTS.md — Архитектурные правила и SDD-оркестрация проекта «Орбита»

## 1. Контекст проекта
«Орбита» — концепт цифрового деканата будущего и учебного пространства студента, разработанный для конкурса «Цифровой деканат будущего».
- **Важно:** Проект является конкурсным прототипом, не является официальным сервисом вуза и использует исключительно вымышленные персональные данные.

## 2. Методология разработки (Spec-Driven Development)
Разработка ведётся строго от спецификаций к коду. Все контракты зафиксированы в директории `/specs`:
- `specs/01_PRODUCT_PRD.md` — продуктовые сценарии, роли, логика БРС, трекер ДЗ и ИИ-консьержа.
- `specs/02_DESIGN_SYSTEM.md` — дизайн-токены, сетка, правила адаптивности от `360px` и анти-вайбкод ограничения.
- `specs/03_DATA_AND_SECURITY.md` — схема данных, модель угроз IDOR, хранение паролей и секретов.
- `specs/04_API_CONTRACT.md` — форматы запросов и ответов REST API.

## 3. Параллельная оркестрация субагентов
Реализация разделена на два изолированных потока с непересекающимися зонами владения файлами:
- **Stream A (Backend & Security Agent):** `prisma/**`, `src/lib/**`, `src/app/api/**`, `src/middleware.ts`.
- **Stream B (Design System & Frontend Agent):** `src/app/globals.css`, `src/app/layout.tsx`, `src/app/(auth)/**`, `src/app/(dashboard)/**`, `src/components/**`.

## 4. Обязательные стандарты безопасности и качества
1. **Изоляция данных (Anti-IDOR):** Любой защищённый эндпоинт обязан извлекать `userId` и `role` исключительно из серверного `HttpOnly` JWT-токена. Передача `userId` с клиента для доступа к чужим сущностям запрещена (`403 Forbidden`).
2. **Защита секретов и паролей:** Пароли хранятся только в виде `bcrypt`-хешей. Ключи API (`JWT_SECRET`, `AI_API_KEY`) используются исключительно на стороне сервера (`process.env`).
3. **UI/UX стандарты:** Строгий запрет на неоновые градиенты и декоративный шум. Обязательное использование `tabular-nums` для числовых показателей и полная работоспособность на экранах шириной от `360px`.
