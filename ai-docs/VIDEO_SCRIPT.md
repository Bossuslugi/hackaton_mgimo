# «Орбита» — сценарий видео-демонстрации (3:30)

> Формат: запись экрана + голос за кадром. Читать с телесуфлёра в спокойном темпе, примерно 130–140 слов в минуту. Паузы `/` — короткий вдох, `//` — пауза на действие.

## Подготовка к записи

- [ ] Стенд пересоздан: `docker compose down -v && docker compose up --build -d` либо `npm run db:setup` и `npm run dev` (или открыть живой стенд).
- [ ] Для локального запуска в `.env` есть `DATABASE_URL="file:./dev.db"` (скопирован из `.env.example`).
- [ ] Браузер в окне 1440×900, масштаб 100 %, закладки и расширения скрыты, уведомления ОС выключены.
- [ ] Тема **Obsidian Dark** (по умолчанию).
- [ ] Алексей по сиду уже записан на «Хакатон цифровых сервисов кампуса». Чтобы показать запись в 1 клик, **перед съёмкой отменить его запись** или записываться на другое событие (например, митап).
- [ ] Во второй вкладке заранее открыт `/login`, чтобы быстро переключиться на деканат.
- [ ] DevTools → Device Toolbar настроен на **360 × 780**, но пока закрыт.
- [ ] Курсор с подсветкой кликов (по желанию).
